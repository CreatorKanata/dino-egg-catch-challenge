# Visual assets

- `dino-charm/`: dinosaur charm illustrations.
- `makerfaire/application/`: application images and the exhibit layout.
- `makerfaire/business-card/`: business card artwork, images, and QR codes.
- `makerfaire/tablecloth/`: tablecloth reference imagery and the print PDF; large editable sources remain local.
- `makerfaire/tshirt/`: T-shirt logo artwork.

## Large local artwork

The following files are intentionally excluded from Git and remain only in the
owner's local working directory:

- `makerfaire/tablecloth/tablecloth_maekake_1800_1570.ai` (about 1.18 GB)
- `makerfaire/tablecloth/tablecloth.psd` (about 781 MB)

They are not downloadable from this repository. The ignore rules preserve local
copies while preventing accidental inclusion in future commits.

The approved tablecloth print PDF (about 46 MB) is stored directly in Git.
