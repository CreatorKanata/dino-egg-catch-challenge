## Validation before submission

- Compare against current form fields and character limits, and any actual submission receipt if available.
- Confirm public maker credit, location, first-time exhibitor status, and full-event availability.
- Confirm booth dimensions, furniture, indoor/outdoor placement, layout, queues, and cable routes.
- Verify operating-mode readiness, prize allocation, KachiButton operation, and NFC tag specifications, destination, and tap experience.
- Verify equipment counts, adapter ratings, measured power, radios, emergency stopping, and motion limits; update the draft accordingly.
- Select images, video, and public URLs, accurately distinguishing completed hardware from planned work.


## Unresolved implementation details

- Confirm whether a dedicated NFC reader is needed or phone-based demonstrations are sufficient.
- Select NFC tag content, destination, and tap experience.
- Confirm the actual radio configuration and the modes and prize allocation available at the event.
